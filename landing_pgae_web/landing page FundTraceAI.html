02 — THE SOLUTION

Three Layers of
Intelligent Defence

FundTrace AI is not a static rule engine. It's a living, reasoning intelligence — built in three complementary layers that reinforce each other with every investigation.

01

Real-Time Transaction Graph

Every fund movement is mapped as a node-edge network in real time. Multi-hop circular patterns — invisible to row-by-row analysis — become immediately apparent as graph cycles.

  • Canvas-based D3-style interactive renderer
  • Live graph updates via Socket.IO
  • Depth-first cycle detection across 5+ hops
→
02

Rule-Based Pattern Engine

Six financial crime categories are detected automatically using configurable weighted scoring. Alerts trigger instantly when a composite fraud score exceeds the threshold.

  • Circular flows, layering, structuring detection
  • Dormant account reactivation alerts
  • Velocity spike and profile mismatch scoring
→
03

Agentic AI Investigator

FraudSense, the AI agent, autonomously queries the live database, reads event logs, recalls past cases, and iterates through evidence until it can issue a confident, cited risk assessment.

  • ReAct (Reason + Act) reasoning loop
  • Persistent episodic memory across cases
  • Confidence scores with explicit uncertainty

04 — SYSTEM WORKFLOW

From Transaction
to Intelligence

Every banking action triggers a cascade of intelligent processes — from real-time rule scoring to autonomous AI investigation — all completing within seconds.

01

Client Action

Bank customer initiates a transaction (transfer, deposit, withdrawal) via the client portal. Authenticated via JWT with httpOnly cookie sessions.

↓
02

Server Processing

Node.js + Express validates, persists to SQLite, and simultaneously triggers the event logger. Every action becomes a structured JSONL event.

↓
03

Rule Engine Scoring

fraud.js evaluates the transaction against six pattern detectors. A weighted composite score is computed. Scores above 50 generate a fraud alert automatically.

↓
04

Real-Time Alert Broadcast

Socket.IO pushes the alert to the officer dashboard instantly. The fund flow graph updates live — showing the new node/edge in the transaction network.

↓
05

FraudSense AI Triggered

If score exceeds 75, FraudSense agent auto-launches. Officer can also manually trigger investigation on any alert. The agent begins its ReAct reasoning loop.

↓
06

Evidence Report Delivered

A structured report with risk level, confidence score, cited transaction IDs, pattern classifications, and recommended actions streams back to the officer dashboard.

05 — DETECTION INTELLIGENCE

Six Categories of
Financial Crime Detected

I
⟳

Circular Transactions

Funds departing Account A return to A after passing through B → C → D — the classic money laundering loop. Detected via graph cycle analysis across unlimited hops.

+40 pts
Graph DFS Cycle Detection
II
⊞

Layering

Rapid multi-hop fund movements designed to obscure the original source. Each hop increases complexity — our multi-path analyser maps every route simultaneously.

+30 pts
Multi-hop Velocity Analysis
III
≡

Structuring (Smurfing)

Large sums split into sub-threshold amounts deliberately. FundTrace aggregates an account's daily total against thresholds to unmask the full picture.

+25 pts
Daily Aggregation Analysis
IV
◉

Dormant Reactivation

An account silent for 90+ days suddenly receives or sends significant amounts. A classic "mule account" activation signature that flags immediate investigation.

+20 pts
Temporal Delta Analysis
V
⊕

Profile Mismatch

Transaction behaviour inconsistent with declared income or occupation. Each account builds a behavioural baseline — deviations trigger weighted alerts.

+20 pts
Statistical Baseline Deviation
VI
↑↑

Velocity Spikes

Abnormally high transaction frequency within a rolling time window. A configurable counter per account/channel flags sudden bursts of activity.

+15 pts

06 — THE INTELLIGENCE CORE

FraudSense:
The Reasoning Agent

FraudSense operates on the ReAct paradigm — Reason, then Act, then Observe, then Reflect. It mimics exactly how a seasoned investigator thinks, but operates in seconds.

🧠
THINK

Analyse available context: account info, alerts, prior memory, known fraud signatures

→
⚡
ACT

Execute a tool: query live DB, read event logs, or retrieve similar past cases from memory

→
👁
OBSERVE

Parse tool output — identify new evidence, gaps, contradictions, or confirming patterns

→
⚖
REFLECT

Is the evidence conclusive? If yes, report. If no, loop again. Up to 8 iterations per case.

↺ Loop until conclusive
AGENT TOOL ARSENAL
db_tool.py
SELECT-only queries on live SQLite — real evidence, not cached summaries
log_reader.py
Parses structured JSONL event history for temporal pattern analysis
memory_reader.py
Retrieves semantically similar past investigation outcomes
memory_writer.py
Persists findings and updates entity behavioural profiles after each case

11 — REGULATORY ALIGNMENT

Built for India's
Compliance Landscape

PMLA 2002

Auto-generated Suspicious Transaction Reports aligned with Prevention of Money Laundering Act requirements. Append-only event log maintains records for mandatory 5-year retention.

RBI KYC 2023

Profile Mismatch detector flags accounts where transaction behaviour diverges from declared KYC data — directly supporting the RBI's Know Your Customer mandate.

FIU-IND STR

Report structure aligned to FIU-IND's Suspicious Transaction Report schema. Optional XML export add-on enables direct portal submission without manual re-entry.

FATF Rec. 20

Socket.IO real-time transaction monitoring satisfies FATF Recommendation 20 (real-time monitoring of wire transfers and electronic fund transfers).

AUDIT TRAIL GUARANTEE

Every transaction, every AI investigation, every officer decision — permanently logged in our append-only JSONL architecture. Nothing is ever deleted. Everything is traceable.
